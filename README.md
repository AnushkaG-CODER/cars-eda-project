# Cars Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a used-cars dataset to understand car prices, fuel types, manufacturing years, kilometres driven, transmission types, and other automobile attributes.

## Objectives
- Understand the dataset and its features.
- Check missing values and duplicate records.
- Clean the data where necessary.
- Calculate descriptive statistics.
- Explore patterns using visualisations.
- Identify outliers and meaningful insights.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Project Files
- `project.ipynb` — Python notebook containing the analysis and visualisations.
- `Cars_EDA_Project_Report.pdf` — Project report describing the analysis and findings.
- `CAR DETAILS FROM CAR DEKHO (1).csv` — Dataset, if permitted to redistribute.

## Key Findings
- Diesel and petrol are the most common fuel categories in the cleaned dataset.
- The mean selling price is higher than the median selling price.
- Manufacturing year has a positive association with selling price.
- The analysis identifies potential price outliers using the IQR method.

## How to Run
1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries: `pandas`, `matplotlib`, and `seaborn`.
4. Open `project.ipynb` in Jupyter Notebook.
5. Make sure the CSV dataset is available at the file path used in the notebook.
6. Run the notebook cells in order.
